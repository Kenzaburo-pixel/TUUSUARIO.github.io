Política de privacidad

Última actualización: 24 de octubre de 2026

Esta política explica qué datos usa Estudio automático, una herramienta personal de Rubén Ibáñez para publicar vídeos en sus propios canales de YouTube.

Quién la usa

Solo su propietario, con sus propias cuentas de Google y sus propios canales de YouTube. No hay usuarios externos ni registro abierto.

Qué datos de Google usa y para qué

Con la autorización que el propietario da a cada canal, la aplicación usa la API de datos de YouTube con estos permisos:

  • youtube.upload: subir vídeos y Shorts al canal autorizado.
  • youtube.force-ssl: poner el título, la descripción, la miniatura y los subtítulos de esos vídeos, y leer los datos básicos del canal y las visitas de sus vídeos para el seguimiento.

No accede a ningún otro dato de la cuenta de Google: ni correo, ni contactos, ni archivos.

Dónde se guardan

El token de autorización de cada canal y los datos de sus vídeos se guardan en un servidor privado del propietario, al que solo él tiene acceso. No se venden, no se ceden ni se comparten con terceros, y no se usan para publicidad.

Uso limitado

El uso que hace Estudio automático de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso se puede retirar en cualquier momento desde myaccount.google.com/permissions. Al hacerlo, la aplicación deja de poder subir vídeos a ese canal.
